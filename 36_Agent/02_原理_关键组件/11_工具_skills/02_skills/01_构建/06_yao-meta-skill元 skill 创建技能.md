项目地址： https://github.com/yaojingang/yao-meta-skill

具体来说，yao-meta-skill 提供了一套完整的工程化流程，帮助你把各种"原始材料"——一段随手写的工作流笔记、一堆重复使用的提示词、一份会议纪要、甚至一张写在便签纸上的操作清单——转化为一个结构化、可评估、可治理、可打包的 Skill 目录。

这个过程不是"写一个文件"，而是一个包含多个阶段的工程流程：
- • 意图对话：先和用户聊清楚"这个技能到底要解决什么真实问题、产出什么、不做什么、符合什么标准"，而不是上来就让填表。
- • 路由设计：用一段精简的 SKILL.md 作为"入口文件"，让 Agent 能准确识别什么时候该触发这个技能。
- • 基准扫描：自动参考行业中高质量的 Skill 作为参照，同时允许用户提供自己喜欢的风格或项目作为学习对象。
- • 质量评估：用训练集/开发集/留出集的方式测试 Skill 的路由准确率，还支持盲评、对抗样本评估。
- • 打包发布：支持跨平台打包（OpenAI / Claude / 通用格式），保留中立元数据和降级规则。
- • 生命周期治理：记录每次迭代的证据、成熟度评分、审查节奏、升级决策。

你可以把它理解成一个 "Skill 的脚手架 + CI/CD" 二合一的工具——帮你从零开始搭建一个合格的 Skill，然后用工程手段持续维护它的质量。
