分享一下我们的新成果：由 LlamaFactory（GitHub 7 万星）原班团队历时半年打造的 Agent Harness：

PenguinHarness: Efficient Self-Improving Harness for 1000+ Models

🌟 什么是 Self-Improving Harness？

1. 你的 AI 算法工程师：0.2 元 + 一句话，生成完整 RAG 应用

PenguinHarness 提供简单、透明、面向 Agent 设计的 SDK 接口。你只需提出需求，Agent 就能在几分钟内开发出接近生产可用的 RAG 应用。过去，我们使用 LangChain 手动开发 Agent；现在，我们让 Agent 以 100 倍速度开发 Agent。

2. Agent 自进化引擎：让每个人都能搭建完整的进化 Loop

在 GDPevo 研究中，我们发现，Agent 已经具备初步的自进化能力，但稳定进化依然很难。因此，我们将过去半年的实践沉淀为开源 PenguinHarness Skills，帮助开发者快速搭建从数据、评估到 Harness 自动迭代的完整 Loop，让 Agent 在垂直领域越用越强。

3. Codex 本地平替，连接 1000+ 模型

PenguinHarness 坚持最小化工具集和系统提示词，已支持 Kimi K3、Qwen 3.8 Max Token Plan 等模型，并可扩展接入 1000 多种模型。在复杂数据分析任务中，PenguinHarness + DeepSeek 取得最高准确率，成本仅为 Claude Code + Opus 的 1/70。
