英伟达开源了自己的 Harness框架：SoL-Pi！英伟达 NVlabs 最新开源了一款 Agent Harness 框架：SoL-Pi；其核心目标是：在保证任务完成质量的前提下，大幅降低 Agent 的 Token 消耗量；
⭐️ 它并不是完全从零开始搭建，而是基于开源的 Pi 框架做的扩展优化；其核心设计是让 Agent 作为研究员，自主研究如何去优化自身的 Harness；
🤖 SoL‑PI 收集了535个高质量测试任务，设计了一套自动研究的循环流水线，让 Agent 观察运行轨迹，定位浪费 Token 的环节，生成优化提案，并在隔离环境中验证效果；

⭐️ SoL‑PI 一共评估了 152 个潜在优化方向，最后找到了4大优化机制：
- 行为融合：让 Harness 改完代码后，把「修改代码文件 + 构建/测试命令」合并成一次工具调用，不需要再多走一轮模型推理；
- 观察归档：把工具返回的超长文本持久化保存在本地磁盘中，只把简短的索引句柄 + 摘要放入模型上下文中，解决了超大工具输出反复塞进上下文的问题；
- 构建了一套轻量级的，可信的执行日志摘要机制：通过较小的模型提炼日志，并逐条校验每个片段是否真实存在于原始日志中；
- 上下文压缩机制：不再等到上下文窗口都快塞满了，才去进行紧急压缩；而是在每个子任务边界主动计算成本，决定是否需要进行上下文压缩；

⭐️ SoL‑PI 的效果也很亮眼：
- 对比原生的 PI 框架：Token 使用量减少了将近一半，API 的调用成本降低到原来 1/3，任务完成质量几乎没受影响；
- 相较于主流的 Harness 框架：Token 使用量最高减少了 64%，调用成本减少一半；
- 在 EdgeBench 等多个基准测试上，SoL‑PI 的得分甚至超越了几个主流的 Harness 框架；
