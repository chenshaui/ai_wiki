很多人以为 Codex 就是「又一个 Claude Code 的竞品」。这句话只说对了一半。真正值得聊的是：OpenAI 把一个起家于 TypeScript、靠 npm 分发的 CLI 工具，推倒重写成了一头 146 万行 Rust 的怪兽——100 多个 crate、Bazel 构建、原生 OS 沙箱（macOS Seatbelt / Linux Seccomp+Landlock / Windows Restricted Token 三层套娃）。这篇文章不聊「谁更好用」，聊的是这套重写背后的工程决策，以及它为什么能撑起一个每周 300 万活跃用户的终端 Agent。

```markdown
openai/codex
├── codex-rs/                 # Rust 主工作区（146 万行）
│   ├── core/                 # Agent 核心循环（~19.8 万行）
│   │   ├── agent/            #   代理编排
│   │   ├── exec_policy.rs    #   命令执行策略决策
│   │   ├── guardian/         #   安全守卫
│   │   ├── skills.rs         #   技能系统
│   │   └── thread_manager.rs #   会话线程管理
│   ├── memories/             # 记忆
│   ├── tui/                  # 终端 UI（~27 万行）
│   ├── exec/                 # 执行事件处理（~5.7 千行）
│   ├── sandboxing/           # 三层 OS 沙箱
│   │   ├── seatbelt.rs       #   macOS Seatbelt（.sbpl 策略）
│   │   ├── landlock.rs       #   Linux Landlock
│   │   ├── bwrap.rs          #   Linux bubblewrap
│   │   └── windows.rs        #   Windows Restricted Token（受限令牌）
│   ├── exec-server/          # 远程执行服务
│   │   ├── server/           #   session_registry / process_handler
│   │   └── client/           #   network_policy_audit

│   ├── codex-mcp/            # MCP 连接管理

│   └── ...（共 100+ crate）
├── docs/                     # 贡献文档

└── justfile                  # 构建编排
```
